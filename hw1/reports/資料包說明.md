# HW1 報告與開發紀錄資料包

這份資料包可用於課堂報告、錄製 demo，以及追查開發過程。

**Git 版本範圍：** 僅收錄正式簡報 PPTX／PDF、講稿、截圖與本說明。下列對話／操作紀錄、Token 附件、manifest 與 ZIP 僅保留在原電腦；從 GitHub clone 不會包含它們。

`../HW1_報告與完整紀錄.zip` 收錄本資料夾、開發驗證說明及現有測試日誌。簡報 PDF 使用逐頁高解析渲染，適合播放；編輯文字與查看講者備註請使用 PPTX。

## 建議使用順序

1. 開啟 `HW1_語音控制系統簡報.pptx`：14 頁可編輯簡報，PPTX 內含每頁講者備註；同名 PDF 方便直接播放與列印。
2. 對照 `HW1_報告與Demo講稿.md`：約 9 分鐘報告，加上 3 分鐘 demo 的錄製順序。
3. 錄影前先實際測試 IP、麥克風及板卡。錄影畫面同時展示桌面結果與 LED，實際結果填入 `../docs/test-record.csv`。
4. 查閱 `HW1_對話與操作紀錄.pdf`：42 頁，包括流程摘要、Token 用量、31 則可見對話及 189 筆工具操作索引。

## 紀錄附件

- `records/conversation.txt`、`conversation.jsonl`：逐則對話。
- `records/operations.txt`、`operations.jsonl`：同編號工具操作的完整可取得輸入與文字輸出。PDF 只節錄較長命令，附件保留可取得的全文。
- `records/token_usage.json`：用量、計算範圍與截止時間。
- `records/manifest.json`：匯出數量、限制及檔案 SHA-256。
- `assets/whisper-desktop.png`：實際新版桌面程式截圖，當時尚未連線。
